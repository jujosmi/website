NO PUBLIC DOWNLOAD IS AVAILABLE YET. CloneHeroAI remains in development. This page will be updated when a build is ready for outside testing.

The project is still being engineered and evaluated. There is no official release package to install from this site right now, and the current research work should not be treated as a stable consumer release.
