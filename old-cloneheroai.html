Clone Hero AI — original project outline

This page preserves the earlier high-level project outline. The current engineering direction is described on the CloneHeroAI project page and in the development log.

ARCHIVED OVERVIEW. The content below records the original concept and is not a claim that each stage is complete.

Project summary

Clone Hero AI analyzes music, identifies useful guitar information, and aims to convert that information into playable five-fret Clone Hero charts. The longer-term goal is to understand guitar parts rather than guess notes from raw audio or generate unrelated patterns.

Capabilities and goals

AreaOriginal objective
Audio analysisExtract timing, beats, rhythm, and guitar-focused information from songs.
Guitar detectionSeparate guitar information from drums, bass, vocals, and other instruments.
Chart generationTurn musical events into five-fret Clone Hero note patterns.
AI learningUse training data and machine learning to improve chart quality and musicality.

Original roadmap

01AUDIO → DATA

Extract useful musical information from songs.

02DATA → CHART

Generate playable note charts from analyzed audio.

03AI CHARTING

Learn guitar patterns, techniques, rhythm, and playing styles.
