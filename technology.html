Technology brief · Guitar Intelligence

Teach the system the performance first

CloneHeroAI is being built as a staged audio-to-chart pipeline. The key principle is to learn meaningful guitar events before asking a chart composer to map those events onto a five-fret layout.

Pipeline architecture

01GUITAR ISOLATION

Separate a guitar-focused signal from the full mix where source audio and separation quality permit.

02EVENT ESTIMATION

Estimate pitch, onset timing, overlapping notes, and useful playing information.

03CHART COMPOSITION

Map the predicted musical events into playable five-fret note patterns and charting styles.

What needs to be learned

SignalWhy it matters
Pitch / fret-related informationProvides the basis for estimating which notes are present, before deciding how to place them on a chart.
Onsets and timingHelps align note events with the actual performance, instead of producing chart patterns that drift or feel unrelated.
PolyphonyAccounts for overlapping notes and chord-like events rather than assuming only one note is sounding at a time.
GeneralizationTests whether the model can handle different guitar tones, recording conditions, and playing styles rather than overfitting one dataset.

Validation before release

Model metrics need to be interpreted alongside meaningful baselines, separate validation data, listening checks, and chart-level evaluation. Improvement on one dataset does not guarantee better behavior on different sources.

Current engineering principle: make upstream predictions more reliable before adding more complexity to the chart-composition stage.
