CloneHeroAI: From Idea to Guitar Intelligence

Jujosmi Labs / PROJECT BLOG / STATUS: IN DEVELOPMENT

CloneHeroAI started as an experiment: could machine learning take a song file and turn the guitar performance into a playable five-fret Clone Hero chart? The answer turned out to be much harder than simply detecting sound and placing notes. The project has gradually become a guitar-understanding problem: separate the guitar from the rest of the song, understand what is being played, identify timing and musical events, and only then turn that information into a chart.

-- WHERE THE PROJECT IS NOW --
Current phase: Guitar Intelligence

We’re at the Guitar Intelligence v0.8 postmortem stage: Guitar-TECHS was successfully added and trained, but v0.8 did not generalize well enough across both datasets. The diagnostics show a strong domain gap, with v0.8 slightly improving on Guitar-TECHS while sacrificing some GuitarSet performance, so the next step is to redesign the training approach for v0.8.1 domain-generalized guitar understanding before moving into chart composition.

UNUSABLE STAGE - Being developed toward a practical release.
Development log 01

What if the chart could make itself?

Begin with the idea - Can a machine learn how to make Guitar Hero Charts? Build the basic architecture and refrences for the model.

Development log 02

The first attempts could make notes — but not necessarily the right notes.

Early experiments demonstrated the basic possibility of automatic chart generation. The system could output note patterns, but generating something that exists is very different from generating something that matches the guitarist.

The important lesson from this stage was that chart generation could not be treated as a simple pattern-making problem. The system needed information about the actual performance first.

Development log 03

Audio2Chart became an important baseline for the project. It showed that a pipeline could go from audio toward automatically produced chart data, but it also made the weaknesses visible.

Timing was not good enough, and the generated patterns did not consistently behave like guitar charts. Having a working baseline was useful because it gave the project something concrete to compare against rather than trying to improve an undefined idea.

Development log 04

The first stage containg a test chart. The results were unpleasant, however, and the charts were dominated by drum like charting patterns.

PROBLEM IDENTIFIED
Development log 05

The pipeline began moving toward guitar-stem isolation before charting. if the charting model receives a guitar-focused signal instead of the entire mix, it has a much better opportunity to learn the information that matters.

Development log 06

Teaching the system what guitar actually is.

Training data became one of the most important parts of the project. The dataset work moved toward paired examples and tolerance-based matching so the model could learn from aligned audio/chart information.

The longer-term goal is for the model to work across different guitar tones, effects, techniques, playing styles and recording conditions rather than memorizing one kind of recording.

Development log 07

Development increasingly focused on guitar intelligence rather than direct chart output. The system needs to understand pitch, onsets, timing, polyphony and playing techniques before it can decide which five-fret notes belong in the final chart.

v0.6 significantly improved pitch recognition. That improvement is part of the larger shift from "make a chart" to "understand the performance first."

Development log 08

v0.7 is focused on the step between guitar intelligence and chart composition: accurate note events. The goal is to make sure the system knows when a guitar event happened and what that event represents before it starts deciding how to place it on a five-fret highway.

-- THE CURRENT PIPELINE --
01 — ISOLATE Focus the pipeline on guitar instead of treating the entire mix as guitar.
02 — ANALYZE Understand pitch, timing, onsets, polyphony and guitar-specific playing information.
03 — GENERATE Turn understood musical events into a playable five-fret Clone Hero chart.
