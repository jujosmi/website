Project blog · Engineering notes

From making charts to understanding guitar

CloneHeroAI started with a simple question: could machine learning take a song file and turn the guitar performance into a playable five-fret chart? The work since then has shown why the problem needs more than note-shaped output.

WHERE THE PROJECT IS NOW: Guitar Intelligence. The focus is on continuing to develop the model to understand with high accuracy the harmonics being played before any chart composing stage is built.

Development history

01

What if the chart could make itself?

The first stage was to test whether a machine-learning pipeline could generate chart data from song audio. It established the broad idea and gave the project a concrete starting point.

02

Making notes was easier than making the right notes

Early experiments could produce note patterns, but generated notes did not always correspond to the guitarist. Producing an output file was not the same as producing a chart that matched the performance.

03

Establishing a baseline

Audio2Chart provided a useful reference pipeline from audio toward chart data. Timing weaknesses and patterns that did not consistently behave like guitar charts made it possible to define what needed improvement.

04

The first test charts exposed a pattern problem

Some generated charts leaned toward drum-like or otherwise unnatural patterns. This reinforced that the system needed to represent what a guitarist was doing, rather than fill a chart with plausible-looking events.

05

Isolate before charting

The pipeline began moving toward guitar-stem isolation. A guitar-focused signal should give the model a better chance to learn relevant information than an untreated full mix.

06

Teaching the system what guitar actually is

Training-data quality became central. Work moved toward paired examples and tolerance-based matching so audio events and chart information could be compared in a more meaningful way across different sounds and performances.

07

Guitar intelligence before composition

The focus shifted toward pitch, onsets, timing, polyphony, and playing techniques. The system needs to understand musical events before deciding which five-fret notes to place.

08

Generalization is the next hurdle

Training experiments showed that stronger results on one dataset do not automatically translate to other recording conditions or guitar styles. The next iterations need to address this domain gap rather than optimize only for one source.

The working pipeline

01ISOLATE

Extract a guitar-focused signal.

02ANALYZE

Understand note events and performance timing.

03GENERATE

Compose a playable chart from learned events.

Main lesson: better charts depend on better musical understanding. The plan is to validate the upstream information before relying on downstream composition.
